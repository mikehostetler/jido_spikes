# Close Kata

**Result:** A defined effort ends with its work preserved, its temporary
resources accounted for, and its remaining obligations assigned.

**Done:** Every required closeout action is verified complete. Retained items
have a reason and an owner. Required evidence remains available after cleanup.
A blocked required action leaves closeout incomplete. A requested dry run is
complete when it returns the proposed actions and evidence gaps without changes;
it does not establish completed closeout.

Read `../methods/kata-closeout/method.md`.

Closeout does not require publication or a merge. An experiment can end with
retained work. Delivery, verification, and repair remain with their existing
owners. Jido retains responsibility for the combined result.

Use only the actions the request authorizes. Permission to close out an effort
does not by itself permit publication, history changes, resource deletion, or
chat archival. Do not request the same authority again when already granted.

A dry run returns proposed actions and evidence gaps without changing files,
Git state, processes, or chats.
